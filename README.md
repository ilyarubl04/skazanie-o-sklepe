# Сказание о Старом Склепе

Маленькое настольное приключение в духе D&D — **на двоих, на одном устройстве**. Один телефон или ноутбук передаётся из рук в руки: компьютер сам ведёт вас как мастер, рассказывает историю, бросает кубики и разруливает бой. Никаких книг правил и подготовки — открыли и играете.

Игра полностью **бесплатная**, работает **офлайн** (после первой загрузки её можно установить как приложение) и не собирает никаких данных.

## Как играть

- **Онлайн:** https://skazanie-o-sklepe-rublevsky.netlify.app
- **Локально:** скачайте папку и откройте `index.html` двойным щелчком в браузере. Всё работает без интернета и без сервера.
- Хотите «как приложение»? Откройте по http(s)-ссылке и добавьте на главный экран — игра запустится в полноэкранном режиме и будет доступна офлайн.

Игра рассчитана на двух игроков за одним экраном. Когда ход переходит к другому игроку, появляется экран «Передайте устройство».

## Управление

- **Выбор героев** — каждый из двух игроков по очереди выбирает себе героя из шести. Нажмите на карточку, прочитайте описание, нажмите «Выбрать».
- **Решения по ходу истории** — выбирайте варианты мышью или тапом.
- **Бросок кубика** — когда нужна проверка (сила, ловкость, ум, харизма), нажмите кнопку броска; результат d20 покажется на экране.
- **Бой** — выбирайте «Атаковать» или способность героя кнопками. Ходы чередуются между игроками и врагами.
- **Музыка и звук** — кнопки ♪ и 🔊 в верхней панели включают/выключают фоновую музыку и звуковые эффекты.
- **Голос рассказчика** — кнопка 🎙️ включает/выключает озвучку (если аудиофайлы сгенерированы, см. ниже).
- **Меню / выход** — кнопка ≡ в верхней панели возвращает в главное меню (прогресс при этом сохранён).

## Сохранение

Прогресс **сохраняется автоматически** в браузере. В главном меню появится кнопка «Продолжить» — она вернёт вас туда, где вы остановились. Отдельно ничего сохранять не нужно.

## Для разработчиков

Чистый ванильный JavaScript, без сборки и зависимостей. Скрипты подключаются обычными `<script src>` тегами, поэтому игра работает даже при открытии файла напрямую (`file://`).

Тесты (запускаются Node, без внешних пакетов):

```
node tests/run.js
```

### Озвучка рассказчика (OpenRouter TTS)

Голос рассказчика генерируется один раз в виде mp3-файлов и зашивается в игру (дальше работает офлайн). Нужен ключ OpenRouter:

```
echo 'sk-or-…' > .openrouter_key          # ключ в .gitignore, в репозиторий не попадает
node tools/generate-vo.js --sample        # сравнить голоса на вступлении
node tools/generate-vo.js                 # озвучить все сцены (центы по стоимости)
```

Файлы появятся в `assets/audio/vo/<сцена>.mp3`, и кнопка 🎙️ в игре оживёт. Модель/голос настраиваются через `VO_MODEL` и `VO_VOICE` (по умолчанию `openai/gpt-4o-mini-tts`, голос `onyx`; для драматичного рассказчика — `google/gemini-3.1-flash-tts-preview` с тегами эмоций).
