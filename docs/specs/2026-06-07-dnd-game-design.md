## 1. Что мы делаем

Браузерная игра в духе Dungeons & Dragons для **двух игроков за одним устройством**. Программа выступает **Мастером**: рассказывает историю, ставит ситуации, просит бросать кубик, ведёт бой. Двое игроков — герои-приключенцы, проходят одно законченное приключение за вечер (~45–90 минут). Прогресс сохраняется, можно продолжить позже.

Правила учить не нужно: всю математику считает движок. Игроку нужно только выбирать действия и бросать кубик.

### Ключевые решения (согласованы с Ильёй)

| Вопрос | Выбор |
|--------|-------|
| Тип мастера | **Готовое приключение + умный движок** (бесплатно, офлайн, без сервера) |
| Устройства | **Одно устройство**, ход переходит по очереди |
| Персонажи | **6 готовых героев** с карточками (выбрал — играешь) |
| Настроение | **Классика фэнтези** (таверна → лес → склеп → босс) |
| Стиль арта героев | **Живописные портреты** в золотых рамках |
| Общий визуал | **«Живой гримуар»** — стол мастера при свечах |

## 2. Архитектура (просто и надёжно)

Главный принцип — **разделить «движок» (правила) и «контент» (историю)**. Тогда историю можно дописывать, не трогая логику, и потом легко добавить новые приключения.

```
index.html            — каркас, экраны, подключение стилей и скриптов
css/styles.css        — вся визуальная система «гримуара»
js/heroes.js          — данные 6 героев (характеристики, способности, тексты)
js/bestiary.js        — данные врагов (волк, скелет, некромант)
js/adventure.js       — приключение как граф сцен (история, выборы, проверки)
js/engine.js          — движок: кубик, проверки, бой, очередь ходов, состояние
js/ui.js              — отрисовка экранов, анимации, печатающийся текст
js/save.js            — сохранение/загрузка (localStorage)
js/main.js            — связывает всё вместе, запуск
assets/portraits/     — 6 портретов героев
assets/enemies/       — арт врагов
assets/icons/         — SVG-иконки способностей (game-icons.net)
assets/fonts/         — шрифты (самохостинг для офлайна)
assets/audio/         — фоновые звуки (CC0)
manifest.json, sw.js  — PWA (офлайн + установка), как у «Котика»
README.md, CREDITS.md — описание и обязательные титры по лицензиям
```

Скрипты подключаются обычными тегами `<script src>` (не ES-модули), чтобы игра работала при открытии файла двойным кликом (`file://`) без сервера.

### Поток данных

1. `main.js` загружает героев и приключение, показывает главное меню.
2. Игроки выбирают 2 героев → `engine` создаёт «состояние партии» (party state).
3. `engine` входит в первую сцену → `ui` рисует текст мастера (печатается), портреты, варианты.
4. Игрок жмёт вариант → `engine` решает: это проверка кубиком? бой? переход к сцене? → обновляет состояние → `ui` перерисовывает.
5. После каждого значимого шага `save` пишет состояние в localStorage.
6. Сцена-концовка завершает партию.

### Состояние партии (party state) — что хранится

```js
{
  heroes: [ {id, hp, maxHp, abilityUses:{...}, statuses:[...]}, {…} ],
  activePlayer: 0|1,        // чей сейчас ход (для передачи устройства)
  sceneId: "tavern_main",   // текущая сцена
  flags: { askedInnkeeper:true, hasRelic:false, … }, // что игроки сделали
  inventory: [ "зелье лечения", "золото:30", … ],
  log: [ … ],               // лента событий
  combat: null | {…}        // активный бой, если идёт
}
```

> Бонус по характеристике для проверок и боя: ● = +0, ●● = +2, ●●● = +4, ●●●● = +5, ●●●●● = +6 (точные числа — в `heroes.js`, при сборке откалибрую на тестовых прогонах).

|-------|------|:----:|:---:|:--:|:---:|:--:|:------:|
| 🛡️ **Бранд, Воин** | Танк/урон ближнего боя | ●●●●● | ●● | ● | ●● | 34 | 14 |
| 🔥 **Лира, Маг** | Магический урон/щиты | ● | ●● | ●●●●● | ●●● | 20 | 11 |
| 🗡️ **Финн, Плут** | Скрытность, замки, ловушки | ●● | ●●●●● | ●●● | ●●● | 24 | 13 |
| ✨ **Сестра Мира, Жрец** | Лечение, нежить | ●● | ●● | ●●●● | ●●●● | 28 | 13 |
| 🏹 **Тэя, Следопыт** | Дальний бой, тропы | ●●● | ●●●● | ●●● | ●● | 26 | 13 |
| 🎵 **Каэль, Бард** | Обаяние, поддержка | ●● | ●●● | ●●● | ●●●●● | 24 | 12 |

### Способности (2–3 на героя)

- **Бранд:** Мощный удар (урон ×2, 2/бой) · Защита союзника (приму удар на себя) · Боевой клич (+2 к атакам обоих, 1/бой)
- **Лира:** Огненный шар (d10+4 урона, 3/бой) · Магический щит (+4 к защите, 2/бой) · Свет (освещение/обнаружение, вне боя)
- **Финн:** Удар из тени (+d8, если враг отвлечён, 2/бой) · Взлом (замки и ловушки, вне боя) · Карманник (добыть предмет/золото)
- **Сестра Мира:** Исцеление (+d8+4 HP союзнику, 3/бой) · Благословение (+2 к броскам, 2/бой) · **Изгнание нежити** (скелеты бегут/получают урон, 2/бой) — особенно силён в этом приключении
- **Тэя:** Меткий выстрел (гарант. попадание +d6, 2/бой) · Следопытство (следы, скрытые проходы) · Зов зверя (помощник на 2 хода, 1/бой)
- **Каэль:** Вдохновение (переброс/+3 союзнику, 3/бой) · Колкая насмешка (враг: d6 и −2 к атаке, 2/бой) · Убеждение (бонус к социальным проверкам)

Каждая карточка героя: портрет в золотой рамке, имя (Cinzel), короткая история (2–3 строки), характеристики точками, иконки способностей (game-icons.net).

## 4. Кубик и правила (для игрока — просто)

- Главный кубик — **d20** (двадцатигранник). Это и есть «камень, который кидается».
- **Проверка:** мастер говорит «брось на Ловкость». Бросок d20 + бонус героя сравнивается со сложностью:
  - Легко 8 · Средне 12 · Сложно 16 · Очень сложно 20.
  - Натуральная 20 — особый успех; натуральная 1 — особый провал (мастер обыгрывает).
- **Бой (по очереди, «в воображении», без поля):**
  - Порядок: сначала ходят оба героя, потом враги.
  - Атака: d20 + бонус ≥ Защита врага → попал. Затем бросок урона (кубик оружия + бонус).
  - У всех есть HP. 0 HP у героя = без сознания (союзник может поднять лечением); 0 HP у обоих героев = поражение (предложим переиграть с контрольной точки).
  - Способности с ограничением «N/бой» восстанавливаются после боя.
- Красивая весомая анимация броска кубика; результат всегда виден и понятен.

## 5. Приключение «Сказание о Старом Склепе»

Завязка: деревня **Тихий Брод**. Каждую ночь со старого склепа на холме звонит колокол — и наутро кого-то недосчитываются. Героев просят разобраться. За проклятием стоит некромант **Морвен**, поднимающий мёртвых звоном проклятого колокола.

Приключение — **граф сцен**. У сцены есть: текст мастера, варианты выбора, иногда проверка кубиком или бой, и переходы к следующим сценам. Часть выборов ставит «флаги», которые влияют на финал.

### Акты и сцены (каркас)

**Акт 0 — Пролог.** Выбор двух героев. Мастер вводит в мир и завязку.

**Акт 1 — Таверна «Утопленный фонарь».**
Узнать слухи. Варианты: расспросить трактирщика (Убеждение/Харизма), подслушать гостей, осмотреть зал (Ум), обчистить пьяного (Карманник). Решение: нанять проводника или идти самим. → флаги: `knowsBell`, `hasGuide`.

**Акт 2 — Ночной лес к холму.**
Встреча: стая волков (или призрачный огонёк-морок). Варианты: принять бой, прокрасться (Ловкость/Следопытство), отпугнуть (Зов зверя/Изгнание/огонь). Первый необязательный бой.

**Акт 3 — Старая часовня.**
Загадка рун, чтобы открыть склеп (Ум; подсказки за исследование). Ловушка на входе (Ловкость/Взлом). **Обязательный бой:** 2–3 скелета (нежить — слаба к Изгнанию и Свету). Находка: записка о Морвене и о реликвии **Светоч**.

**Акт 4 — Глубины склепа.**
Развилка: левый путь — сокровищница с ловушкой (риск/награда), правый — короче, но со стражем. Находки: зелья лечения, золото, реликвия **Светоч** (если найдут — ослабит босса). Мини-столкновение.

**Акт 5 — Зал колокола (финал).**
Босс — некромант **Морвен**, призывающий скелетов. Несколько развязок:
- **Силой:** победить Морвена в бою.
- **Светом:** если есть Светоч или активное Изгнание — разрушить колокол, резко ослабив босса.
- **Хитростью:** при высокой Харизме и собранной информации — переубедить/упокоить Морвена почти без крови.

### Концовки (зависят от выборов и бросков)
- **Светлая:** проклятие развеяно, пропавшие спасены, деревня благодарна.
- **Горькая:** победа, но дорогой ценой (потери среди пропавших / тяжёлые раны).
- **Хитрая:** Морвен упокоен с миром, раскрыта его трагическая история.
- **Поражение:** оба героя пали → мастер предлагает переиграть с последней контрольной точки.

Несколько концовок дают смысл переигрывать другими героями и другими решениями.

### Враги (для боя)

| Враг | HP | Защита | Атака | Урон | Особое |
|------|:--:|:------:|:-----:|:----:|--------|
| Волк | 10 | 12 | +3 | d4+1 | в стае нападают вместе |
| Скелет | 12 | 11 | +3 | d6 | слаб к Изгнанию/Свету |
| **Морвен (босс)** | 60 | 14 | +5 | d8+3 | призыв скелета (раз в 2 хода), тёмная волна по обоим (d8); Светоч/Изгнание снимают часть HP и призыв |

(Точные числа откалибрую на тестовых прогонах при сборке, чтобы бой был честным и не затянутым.)

## 6. Очередь ходов на одном устройстве

- Сверху всегда: **«Ходит: Игрок 1 — Бранд»**.
- Сюжетные тексты и общие выборы игроки обсуждают вслух; жмёт активный игрок.
- При смене активного игрока — мягкий экран **«Передайте устройство Игроку 2»**, чтобы не путаться.
- В бою действия идут по очереди героев, затем враги.

## 7. Визуальная система «Живой гримуар»

Цель — чтобы игрок **находился** в игре, а не читал простыню текста.

### Цвета (токены)
- Фон-тьма `#0f0a04`, пергамент `#c9a96e`, золото `#d4a853`, кровь-багрянец `#8b0000`, изумруд-акцент `#2e6b4f`, тёплый текст `#f0e6c8`.

### Шрифты (Google Fonts, OFL, бесплатно; самохостим в `/assets/fonts` для офлайна)
- Заголовки/масштаб: **Cinzel Decorative** (золочёные, как иллюминированные буквицы).
- Подзаголовки/метки: **Cinzel**.
- Текст истории: **EB Garamond** 17–18px, межстрочный 1.75, тёплый цвет на тёмном (не чисто белый на чёрном — иначе тонкие засечки «плывут»).
- Курсив-заклинания/флавор: **IM Fell English Italic**.

### Эффекты (всё на CSS/ванильном JS)
- Фон: тёмная виньетка по краям + тёплое свечное свечение по центру (двойной radial-gradient).
- Панели-пергамент: цвет + слои градиентов + текстура бумаги (CC0 ambientCG) на низкой прозрачности с `mix-blend-mode: multiply` + зерно через инлайновый SVG-фильтр `feTurbulence` (ноль запросов).
- **Печатающийся текст мастера** (буква за буквой, ~30мс) — главный приём погружения, будто мастер говорит.
- **Буквица** (drop cap) на старте каждой сцены — крупная золочёная заглавная.
- Золотое свечение заголовков (многослойный `text-shadow`).
- Кнопки-выборы как **сургучные печати**; рамки — золотые (CSS `border-image`/SVG data-URI).
- Анимации (карточки, появление, лёгкая тряска при ударе) — ванильно или лёгкая `anime.js` (MIT, 24КБ) при необходимости.
- Кубик d20 — весомая анимация (свой код на CSS/Canvas, либо `css-dice-roller` 15КБ, MIT).

### Экраны
1. **Главное меню** — «стол мастера при свечах»: название (Cinzel Decorative), кнопки «Новая игра», «Продолжить», «Титры».
2. **Выбор героев** — 6 карточек с портретами в золотых рамках, перелистывание, итог «Игрок 1 / Игрок 2».
3. **Сцена** — панель мастера (печатающийся текст + буквица), портреты активных героев, варианты-печати.
4. **Бой** — портреты, полоски HP, кнопки способностей с иконками, поднос для кубика, лента боя.
5. **Концовка** — атмосферный текст финала, итоги, «Сыграть снова».
6. **Титры** — обязательные кредиты по лицензиям.

## 10. Сохранение, техника, публикация
- Сохранение партии — в `localStorage` (выбранные герои, сцена, флаги, HP, инвентарь, заряды способностей). Кнопка «Продолжить» в меню. Контрольные точки между актами.
- Чистый HTML + CSS + JavaScript, без фреймворков и сервера. Лёгкие либы (anime.js / css-dice-roller) — только при необходимости, локально.
- Офлайн: PWA (manifest + service worker), шрифты и ассеты самохостим.
- Публикация: личный GitHub `ilyarubl04` + Netlify (как «Котик»).
- После правок — `node --check` на скриптах и открытие через `open` для проверки.

## 12. Риски и как их снимаем
- **Баланс боя** — калибрую на тестовых прогонах, чтобы не было слишком легко/долго.
- **Согласованность портретов** — беру единый набор из одного источника (или единый ИИ-стиль), чтобы 6 героев смотрелись как одна команда.
- **Офлайн-шрифты** — самохостим woff2, не полагаемся на CDN.
- **Звук в Safari** — «разблокировщик» по первому касанию (проверенный приём из «Котика»).
- **Объём контента** — текст приключения пишу как данные; при росте легко резать/добавлять сцены.
